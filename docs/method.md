# SOPNet 方法

## 任务形式

多数极性判别方法把初动判定当作离散分类问题。SOPNet 改为预测一个
**带符号起始场（signed onset field）**

```
f : R^T -> [-1, 1]^T,        T = 400 个样本（100 Hz 下 4 秒）
```

以带符号高斯场为训练目标：

```
g(t) = s * exp(-(t - t_P)^2 / (2 sigma^2)),
s = +1（上）, -1（下）, 0（未知）
```

默认 `sigma = 10` 个样本。P 波到时、极性与置信度都来自同一个输出：

```
t_hat = argmax_t |f(x)(t)|,   s_hat = sign(f(x)(t_hat)),   C = max_t |f(x)(t)|
```

该表示有三个实际优势：

1. 极性与 P 波定位联合求解；按构造，"极性可信但到时未定位"的情况不可能出现。
2. `C` 是天然的置信度，可实现选择性预测，并用验证集调出的未知阈值替代硬性第三类。
3. 对参考窗口偏移的鲁棒性更好，因为网络必须去寻找起始点，而不是假设固定位置。

## 网络结构

紧凑的一维多尺度编码器-解码器（1.44 M 参数）：

```
输入 [1, 400]
  多尺度 stem（k = 5, 11, 21）            -> 48 x 400
  残差编码器 400 -> 200 -> 100 -> 50      -> 64/96/128
  空洞瓶颈层 d = 1, 2, 4, 8               -> 192 x 50
  带跳连的解码器 50 -> 400
  Conv1d(1) + tanh                        -> 带符号场 [1, 400]
```

`SOPNet-Cls` 与 SOPNet 共享完全相同的编码器，只加全局平均池化与线性分类器，
作为容量对齐的消融对照。

## 损失函数

```
L = L_field + lambda_pol * L_pol + lambda_inv * L_inv
```

- **加权带符号场损失**（`beta = 8`）：

  ```
  L_field = mean_t (1 + beta |g(t)|) * SmoothL1(f(t), g(t))
  ```

- **极性一致性**（不增加额外分类头）：令 `w = softmax(kappa |f|)`、
  `q = sum_t w_t f_t`，则

  ```
  L_pol = log(1 + exp(-gamma * s * q))     （仅已知极性样本）
  ```

- **反转一致性**（约 25 % 的 batch 上施加）：

  ```
  L_inv = mean |f(-x) + f(x)|
  ```

默认权重：`lambda_pol = 0.5`、`lambda_inv = 0.1`。

## 训练协议

AdamW（`lr = 1e-3`、`wd = 1e-4`）、带 5 % warmup 的余弦衰减、梯度裁剪 1.0、
AMP、batch 1024、按验证集 U/D 准确率早停（patience 10）。训练窗口随机裁剪，
使 P 起始点均匀落在第 120-280 个样本之间，防止网络记住固定的起始位置。
数据增强：基于 SNR 的高斯噪声（0-30 dB，p = 0.35）、极性反转
（U <-> D，X 不变，p = 0.5）和轻度幅度缩放。

> 已知 U/D 样本上计算（`configs/experiments/sopnet_nojitter.yaml`）。上述 jitter
> 协议是原始设计；两种配方的对比见 `docs/results_v1.md`。
